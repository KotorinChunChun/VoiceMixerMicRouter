# マイク常駐v1.0.17 実装計画・報告

出典：2026-10-19の設定画面改修依頼。

## 要求と判断

- ブラウザ音声キャプチャの導入・設定案内を撤去し、指定された公開GitHubへのリンクを置く。現在のoriginは非公開のため公開先URLを確認中。公開設定自体は変更しない。
- 基本設定の表示方法・ログインモードを、デバイス欄と同じX=190、幅545へ揃える。
- 短音抑制の原理をツールチップにする。既存の入力履歴で衝撃音を判定し対応するRVC出力区間を抑えること、追加の音声待ちを設けないこと、声との重なり等の限界を説明する。
- RVCの各ラベルに意味・値の影響・再起動要否のツールチップを付ける。RVC使用チェックにも説明を付ける。
- モデルとIndexは既存の編集可能コンボで任意の絶対パスを保存できることを維持し、選択ファイルのフォルダーを開くボタンを追加する。空欄時は定義された既定の保存フォルダーを使い、存在しないフォルダーは作らずエラーを示す。
- キー設定の下部に「共存」「上書き」の説明を置く。キー検出・音声処理・利用者の保存値は変更しない。

## 工程

- [ ] 1. 設定UI・ツールチップ・フォルダー操作と回帰、ビルド・コミット。
- [ ] 2. 実画面確認・設定保持配備、仕様と結果の更新・コミット。

通常回帰と設定GUI・オーバーレイGUIを実施する。公開GitHubのリンク先は確認回答を待ち、公開／公開設定変更へ拡張しない。旧ブラウザ案内HTMLはMicRouter専用で他の参照がないことを確かめて撤去する。
