# マイク常駐の検証記録

## v1.0.17・独立化（2026-10-19）

VoiceMixer内のv1.0.16から独立manifestとGitへ分離した後、元のチェックアウトをソース依存に含めず通常76件が成功。v1.0.17は通常77件成功・条件付き実機6件除外、設定GUIとオーバーレイGUI各1件成功、all-features checkとReleaseビルド成功。既存のビルドキャッシュだけを一時共用した。

モデル／Indexのフルパスと引用符付き入力、相対指定・空欄の既定フォルダー・存在しないフォルダーを自動作成しないことを回帰確認した。設定GUIでは全項目の配置・重なり・フォーカス・タブ・無効化・保存値の往復を検証した。標準Tooltipの登録はcomctl32 V2サイズで対応した。

配備版の対象設定ウィンドウだけを撮影し、基本コンボのX/W一致、公開GitHubリンク、RVCフォルダーボタン、キー動作の説明を目視した。実マウスのホバーで短音抑制・音声モデル・推論ブロック長のツールチップ本文を確認し、モデルの保存フォルダーボタンから期待するフォルダーがExplorerで開くことを確認した。検証で新規に開いたExplorerだけを閉じた。最初のツールチップ読取はGetWindowTextで空となったが、WM_GETTEXTで本文を確認できた。

音声処理とキー検出の挙動は変更していない。実モデル・音響遅延・MSTSC・実ログインは今回再測定していない。v1.0.16のMSTSC前景のShift+F12はユーザー確認済みという履歴を引き継ぐ。新しい測定と同一視しない。

設定・未保存128項目と元の基本タブ、MICモードを新しい配備先へ引き継いだ。RVC環境は利用者の設定にある外部の配置先をそのまま使用する。モデル・Python/CUDA環境をGitへ追加していない。

最終配備版：PID26256、単一プロセス、MIC取得active=true。保存設定の前後ハッシュ一致。ビルド／配備EXEのSHA256は双方56711A7BFD34653235188052074C55F24BB5979BF4AE2ECD0FB9FA0E2A62207A。既存Startupの起動先・設定引数を新配備先へ更新した。
