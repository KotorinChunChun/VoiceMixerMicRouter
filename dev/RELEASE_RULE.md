# リリースルール

常駐版は独立管理し、通常の更新は末尾だけ1ずつ増やす。APP_VERSIONとCargo.tomlの版、画面とCLIを一致させる。

1. 通常回帰・必要なGUI・ビルドを確認する。
2. 設定と未保存編集、稼働状態を保持してローカル更新する。
3. モデル・実行環境・個人設定・認証情報・録音・private/tempを除外し、gitの公開対象を確認する。
4. 公開を依頼された範囲でGitHubへpushする。署名・Releaseバイナリ・ストア公開は別工程。
5. 完成資料をhistoryへ移し、結果に実測と未確認の範囲を残す。

起動・検証・配備コマンドは[開発者ガイド](../docs/DEVELOPERS_GUIDE.md)を参照する。Install-MicRouter.ps1の-NoStartupを外すと現在ユーザーの既存Startupショートカットを更新する。モデルと個人設定は公開成果物に同梱しない。
