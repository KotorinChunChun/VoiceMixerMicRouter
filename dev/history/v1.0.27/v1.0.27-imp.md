# v1.0.27 設定ボタンの常時着色と既定マイク

- オーバーレイの設定ボタンを常に青緑で表示する。設定画面が開いている間は明るい色を使う。
- 初回起動、CLIの設定生成、基本設定のリセットで、入力マイクを「既定のデバイス」にする。Windowsの録音既定を表す論理IDを使う。

通常回帰99件と、独立したWindows設定画面およびオーバーレイの試験2件に成功した。設定を閉じた状態と開いた状態の配色は描画の回帰試験で照合した。CLIで生成した設定の入力マイクは「既定のデバイス」だった。

常駐していたv1.0.25を通常終了し、同じ設定でv1.0.27を起動した。実際の設定画面で個別マイクを選んでからリセットし、「既定のデバイス」に戻ることを確認した。試した変更は適用せず、再起動前と保存ファイルが一致することを確認した。常駐のオーバーレイ表示は保存設定でオフだったため、配色の確認には回帰試験を使った。
