# v1.0.30 基本設定からRVCタブを切り替える

「RVCを使用する」を基本設定の「ログイン時のモード」の下へ移した。OFFではRVC設定タブをグレー表示し、クリックで開けないようにする。矢印キーやCtrl+Tabでのタブ移動はRVC設定を飛ばす。チェックによる画面の切替は即時、音声の設定は「適用」で反映する。

基本設定のリセットはRVCの使用もOFFに戻す。RVC設定のリセットはモデルなどのパラメーターを戻す。

Windows設定画面の回帰試験で、OFFのときのクリックと矢印キー、ONにしたときの表示、両タブのリセットを確認した。v1.0.28を通常終了し、v1.0.30の実画面でもOFFのグレー表示とクリックの抑止、ONに切り替えると適用前に開けることを確認した。確認用の操作は適用せず、保存ファイルが再起動前と同じであることを確認した。
