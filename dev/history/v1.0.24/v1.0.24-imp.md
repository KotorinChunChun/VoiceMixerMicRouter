# v1.0.24 設定行の均等配置とデバイスの未選択対応

対象は VoiceMixerMicRouter。v1.0.23 からの変更と確認結果。

## オーバーレイの設定行

「表示」「ノイズ」「設定」を左から同じ幅で並べる。現行の設定行は左から146、158、80px。出力行と同じ3等分を使い、ラベルの右側に128pxのボタンを3つ、間隔4pxで配置する。

| ボタン | X座標（右端を含まない） | 表示例 |
| --- | --- | --- |
| オーバーレイ表示 | 56–184 | 表示[F12]数秒 4秒 |
| ノイズ抑制 | 188–316 | RVCノイズ[F24] ON |
| 設定画面を開く | 320–448 | 設定 |

高さは21px。表示モードの「数秒表示」は、このボタン内では「数秒」と表記する。ノイズの状態、割当済みの主キー、残り秒数を表示し、最も長い組み合わせを12pxの実フォントで確認する。描画・クリック・カーソル判定は同じ矩形を使う。設定ボタンは設定画面を開き、開いている場合はその画面を前面に戻す。

## 基本設定の5つのデバイス欄

SpkRouterの候補順と、使わない入力をオーバーレイから隠す動作を参考にする。MicRouterでは基本設定でも未選択行をたたむ。

「入力マイク」「入力スピーカー」「出力1」「出力2」「出力3」の候補を次の順にする。

1. 未選択
2. 既定のデバイス
3. 既定の通信デバイス
4. 個別デバイスと保存済みの未接続デバイス（名前順）

入力マイクには録音デバイス、入力スピーカーと出力には再生デバイスを並べる。保存・復元はデバイスIDで行う。未接続の保存先には「（未接続）」を表示し、選択済みの行として残す。効果音の再生先は別の設定欄とする。

基本設定を開いた直後は、未選択のデバイス行をたたみ、表示する行を上から詰める。「未選択の欄を表示」で5行を開き、「未選択の欄を隠す」で再びたためる。選択済みの行を編集中に「未選択」へ変えても、その行は適用までは残る。適用に成功したら、新しい選択を基準にたたむ。閉じると未適用の編集は取り消せる。

出力を未選択にすると、その行の「有効」はOFFになり操作できなくなる。デバイスを再選択したときは、有効を手動でONにできる。用途名とキー割当は保持する。

## 初期値と既存設定

| 出力 | 新規作成時の再生先 | 初回通常起動時の有効状態 |
| --- | --- | --- |
| 出力1 | 既定のデバイス | OFF |
| 出力2 | 未選択 | OFF |
| 出力3 | 未選択 | OFF |

通常起動の初回生成とCLIの `--init` は、同じ出力先の初期値を使う。通常の初回起動は送信停止。入力マイクと入力スピーカーの初期値は現行どおりとする。

未選択は空のIDで保存する。OSの既定と通信既定は既存の論理IDで保存する。読込時は既存の出力先・有効状態を引き継ぐ。旧版が「空欄から既定の出力3を補う」としていた設定と、今回明示的に保存した「未選択」は、デバイス選択の形式を示す版で区別する。旧版のCABLE-D自動検出は旧形式の設定に限定し、新規作成や明示的な未選択への再割当には使わない。

## 未選択のときの操作と音声

| 欄 | 未選択で利用できなくなる操作 |
| --- | --- |
| 入力マイク | MIC、MIC-RVC、MICとMIC-RVCの交互切替 |
| 入力スピーカー | SPK-RVC |
| 出力1〜3 | 該当出力の切替と「押している間ON」 |

利用できない入力・出力をオーバーレイとトレイから隠す。オーバーレイでは行ごとに残るボタンを均等に配置し、メーターを対応するボタンの直下に置く。全出力が未選択のときは出力行を表示しない。送信停止と設定を開く操作は常に使える。RVCの使用設定も従来どおり反映する。

キー設定では対応行をグレーアウトし、保存済みの割当を保持する。未選択中はグローバルキーを有効化せず、「上書き」のキーもOSへ渡す。効果音タブの7項目は選択中のデバイスにかかわらず編集できる。利用できない操作のキー・コマンドでモードや出力を変更せず、切替音も鳴らさない。ログイン時のモード欄で未選択の入力モードは新たに選べない。保存済みの起動モードや前回モードが未選択の入力を使う場合は送信停止で起動する。

現在使っている入力を未選択にして適用すると、送信停止へ移り、その入力の取得を止める。出力を未選択にした場合は該当する出力を止める。押下中にその出力が未選択になった場合は押下状態も解除し、選択し直した後は新しい押下で動作する。未選択のデバイスを開いたり、OSの既定で代用したりしない。接続済みの経路には従来の循環検知と重複出力抑止を適用する。

## キー設定と効果音のリセット

キー設定と効果音の各タブに「初期値に戻す」を置く。対象タブの編集値だけを変え、「適用」で確定する。基本設定やRVC設定の編集値は保持する。

- キー設定は14行の有効状態、修飾キー、主キー、共存・上書きを新規設定と同じ値に戻す。出力3の「押している間ON」は左Ctrl＋左Shift、主キーなし、共存に戻す。出力3が未選択なら、割当を保存してデバイス選択後に使えるようにする。
- 効果音はMIC、MIC-RVC、SPK-RVC、送信停止、出力1、出力2、出力3の順に音1〜音7に戻し、再生先を「既定のデバイス」に戻す。リセット操作では試聴しない。
