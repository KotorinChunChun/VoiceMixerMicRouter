# v1.0.32 隔離CLIテスト

1. 通常の起動経路から独立した、JSONシナリオを実行するCLI入口を設ける。
2. 設定検証、初期値、出力排他、音声経路、効果音の生成、オーバーレイの表示条件を既存処理と共有する。
3. 配布用バイナリと同じCLI入口で、状態遷移、失敗時の保持、通常常駐への非干渉を確認する。

## 実装

`--test-scenario` は通常起動より先に分岐する。シナリオと結果はJSONで、状態は試験プロセスのメモリーに保持する。再起動操作は適用済み設定をJSON経由で復元する。設定適用の検証に失敗したときは、実効出力と適用済み設定を維持する。

試験は製品と共通の初期値、設定・RVCパラメーター検証、音声経路生成、出力切替と押下中の排他、効果音波形、オーバーレイ表示条件を使う。通常常駐へのIPC、グローバルキー登録、設定ファイルへの書き込み、実デバイスへの接続は行わない。

## 検証結果

- Rustの通常回帰100件とWindows設定画面の回帰1件が通過した。
- デバッグ・リリースの両構成で試験シナリオ35操作が成功した。操作失敗時のロールバック、不正JSONと通常引数の拒否、終了コード0／1／2も確認した。
- リリース構成の試験中に導入済みv1.0.31が同じPIDとEXEで稼働し、利用者設定と試験入力のSHA-256が変化しないことを確認した。
- 隔離CLIの対象は状態遷移・音声経路・波形・表示条件。実音声の出力、RVC推論、Windowsの実キー操作と実画面表示はこの試験の対象外。

## 公開前の修正

v1.0.31でToysから初めて設定を開く際に応答が途切れた。設定画面では候補のID・名前・接続状態だけを取得し、デバイスごとの音声クライアント生成と対応形式の照会を省いた。音声診断用の列挙は従来どおり。管理試験ではToysと同じ2秒の期限で応答を検査し、初回表示の所要時間を記録する。
