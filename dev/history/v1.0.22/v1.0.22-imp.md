# v1.0.22 オーバーレイの設定ボタン

2026-11-08。SPK版と同様に、MIC版のオーバーレイ右上から設定画面を開けるようにする。

- [x] 設定行に「設定」を追加し、設定画面の表示中は既存画面を前面に戻す。設定画面中の他のクリック操作は従来どおり抑止する。
- [x] 表示・ノイズ・入力・出力の既存操作、ドラッグ、数秒表示を保ち、文字幅とヒット判定を確認する。
- [x] ビルドと関連試験、音声を起動しない独立オーバーレイの操作試験を行い、文書とローカルコミットを整える。

結果：オーバーレイ関連の通常試験10件と、独立したWin32オーバーレイでのクリック試験1件が成功。設定画面中の設定ボタン、他操作の抑止、適用待ち中のMIC・停止、ボタンの点灯状態を検証した。設定・ノイズのON／OFF・F24付き文字列は実フォントの幅を測定し、表示領域に収まることを確認した。使用中のv1.0.21を終了せず、別のビルド先でv1.0.22のDebug EXEを生成し、CLIと製品情報の版番号を確認した。既存の常駐が使用中のため、通常の通知領域を含む一体GUI試験と物理マウスでの操作は実施していない。導入済みアプリや利用者の設定は変更していない。
