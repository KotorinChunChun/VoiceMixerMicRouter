# v1.0.31 RVC無効時の起動と設定の改善

[要求](v1.0.31-req.md)に沿って、起動時のモード判定、キーの有効条件、RVC設定の保存、未接続出力の操作を修正した。

- RVCがOFFならログイン時にRVCモードを新規選択できない。保存済みのRVC指定は保持し、「送信停止（RVC無効）」と表示する。保存済みまたは前回のRVCモードで起動する場合は送信停止にする。
- 「入力モードを交互に切替」はRVCがOFFなら設定欄、キー登録、常駐側の操作を無効にする。割り当ては保持する。
- RVC設定を編集してOFFにしても、「適用」で編集値を保存する。
- 未接続出力は保存先を保持する。新たな有効化を抑止し、すでに有効ならOFFにできる。デバイス欄のツールチップに再接続後の確認手順を表示する。

通常のRustテスト100件とWindows設定画面の回帰テスト1件に合格した。隔離設定でv1.0.31を再起動し、常駐の状態が送信停止で、交互切替コマンドの実行後も同じことを確認した。実画面でRVC無効時の起動候補、交互切替のグレー表示、未接続出力の無効表示を確認した。ピッチを3に編集してRVCをOFFで適用し、設定ファイルと再起動後の画面で値を確認した。ツールチップは登録を回帰テストで確認した。吹き出しの目視確認と音声の試聴は未実施。
