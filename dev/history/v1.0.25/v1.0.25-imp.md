# v1.0.25 基本設定とRVC設定の初期値

- 基本設定とRVC設定に「初期値に戻す」を追加する。リセットの対象は操作したタブとし、「適用」で反映する。
- 基本設定は初回の入出力先・出力状態・用途名・常時表示・前回のモード・短いノイズの抑制に戻す。
- RVC設定は使用をOFFにし、モデル、ピッチ＋10、RMVPEなどを初回値に戻す。OFFの間もリセットを使え、適用時に保存できる。既定の実マイクが検出できない初回起動でも同じRVC初期値を使う。

初回起動と既存設定の保持を検証する2件、および独立したWindows設定画面での操作試験が成功した。基本設定の既定値、RVCがOFFのときのリセット、基本設定のノイズ抑制と効果音タブの編集中の値、保存前の設定保持を確認した。検証では稼働中のv1.0.24を維持した。

隔離先のDebugビルドとCLIの版表示は1.0.25を確認した。Releaseプロファイルの試行ではAWS-LCのネイティブ依存のビルドが失敗した。動作確認はDebug版で実施した。
