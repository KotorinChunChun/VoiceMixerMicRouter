# 独立化の記録

2026-10-19、ユーザーの「新たにVoiceMixerMicRouterとしてPublicで作って公開。独立化を優先」という依頼に基づき、VoiceMixerの常駐v1.0.16を独立プロジェクトへ分離した。

- 由来はVoiceMixerの037f312時点。元のGit履歴は移さず、常駐・必要な共通音声Backend・埋め込み素材・RVCスキーマとPython処理を選択コピーした。
- マイク常駐以外のbin・Web画面・元の開発資料・個人設定・モデル・ランタイム・録音は移していない。
- ローカルの作業先とGitルートはC:/develop/VoiceMixerMicRouter。本体のGitとは独立する。
- 共通Backendのソースも独立リポジトリ内で保持する。過去の本体機能に関係する未使用モジュールは大きな挙動変更を避けて保持した。Tauri用feature/build依存は常駐のビルドから外した。
- 上流RVCライセンスは維持し、作者のコードへの新しいライセンス条件は推定して追加しない。
- 元の常駐配備を維持したまま、分離後のビルドと通常回帰を先に確認する。

独立manifestでの通常回帰：76件成功、条件付き実機6件除外。元と同じedge-websocket既定を維持し、単独ソースからコンパイルできた。ビルドキャッシュのみ元のtargetを一時共用した。
