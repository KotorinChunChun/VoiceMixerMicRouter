ブラウザ音声キャプチャ

インストール案内 ／ 設定案内

インストール

VoiceMixer Edge PCM拡張をEdgeまたはChromeへ手動で読み込みます。

  1. 配布された拡張フォルダーを用意します。ソースから作る場合はVoiceMixerのフォルダーで、次を実行します。
    npm --prefix .\src\edge-extension install
npm --prefix .\src\edge-extension run build
  2. Edgeではアドレス欄にedge://extensions、Chromeではchrome://extensionsを入力します。
  3. 「開発者モード」をONにして「展開して読み込み」を押し、配布フォルダー、またはビルド済みのsrc/edge-extension/distを選びます。
  4. 拡張アイコンをツールバーへ固定します。更新時は拡張カードの「更新」を押します。拡張全体の再読み込みは実行中の全タブへ影響するため、エラー時の最後の手段にしてください。

設定と音声の受け渡し

VoiceMixerMicRouterは拡張PCMを直接受信しません。ブラウザの再生音をRVC変換する場合は、次の方法を使います。

  1. ブラウザの再生先を、MicRouterの「入力スピーカー」に指定したデバイスへ合わせます。出力1〜3には別のデバイスを指定します。
  2. 拡張の「同時再生」をONにします。拡張による転送が不要なら、拡張を使わず通常のブラウザ再生音をそのまま取得することもできます。
  3. MicRouterの「RVCを使用する」をONにし、SPK-RVCを選びます。選択スピーカーで再生される他のアプリの音も取得対象です。

タブだけをVoiceMixer／SpkRouterへ送る場合

  1. 受信側のポートと認証トークンを、拡張の共通接続設定へ入力します。接続先は同じPCの127.0.0.1です。MicRouterの設定値ではなく受信アプリの設定値を使います。
  2. 対象タブで拡張アイコンを押し、サイドパネルを開きます。カードのストリームキーを受信側のキーと一致させて保存し、「キャプチャ開始」を押します。サイドパネルを開くだけでは開始しません。
  3. SpkRouterは「ブラウザ」を選びます。初期ポートは18766、初期ストリームキーはspk-routerです。トークンはそのアプリの現在の値を使います。本体／Runnerと同時に使うときはポートを分けます。
  4. 必要なら受信側から仮想ケーブルへ出力し、その再生デバイスをMicRouterの「入力スピーカー」に指定してSPK-RVCで変換します。MicRouterの出力先は別のデバイスにしてください。

接続できない場合は受信アプリの起動、ポート・トークン・ストリームキー、キャプチャ許可を確認します。停止したタブは同じカードから再開できます。
