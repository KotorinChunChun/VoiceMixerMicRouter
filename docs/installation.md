# インストールとRVCの追加設定

Windows 11 x64向けです。GitHub Releasesから対象バージョンの `VoiceMixerMicRouter-<版>-setup.exe` を取得して実行してください。利用者単位でインストールでき、管理者権限やWindowsの再起動は不要です。未署名の開発版です。SHA256SUMS.txtで配布物の整合性を確認できます。

## 初回起動

スタートメニューのVoiceMixerMicRouterを開くと、送信停止・RVC無効・出力OFFで設定画面を表示します。入力マイクと出力デバイスを選び「適用」してください。モデルや仮想ケーブルが未導入でも設定できます。

設定はLocalAppData/VoiceMixerMicRouter/mic-settings.jsonへ保存します。既存のEXEと同じフォルダーにある設定や、--configで明示的に指定した設定も引き続き使えます。インストーラがそれらの設定を自動で取り込むことはありません。現在の設定を移す場合は、旧常駐を終了してから設定を新しい保存先へコピーし、plugin_directoryが指す既存のRVC環境を確認してください。個人設定を公開配布物に含めないでください。

## RVC追加設定

この基本配布にはRVCの設定スキーマ・自作Pythonワーカーを含みますが、Python/CUDA実行環境・上流推論コード・音声モデル・Index・仮想オーディオドライバーは含めません。RVCを使用するには対応GPUと別途用意した実行環境、利用するモデルが必要です。

既存環境がある場合は常駐停止中にmic-settings.jsonのplugin_directoryへrvc-cudaを含むpluginsフォルダーを指定してください。新規に配置する場合は[プラグインの説明](../plugins/rvc-cuda/README.md)を確認してください。RVC設定の音声モデル／検索Indexは任意の絶対パスを直接入力でき、フォルダーを開くボタンも使えます。環境とモデルを用意してから「RVCを使用する」をONにして適用します。環境未準備のRVCで原音を勝手に流すことはありません。

## 更新と削除

設定画面を閉じ、適用中の処理が完了してから新しいsetupを実行します。インストーラは導入先の製品情報と管理PIDを照合し、アプリが正常終了したことを確認してから更新します。別の場所に配置したアプリから応答がない場合や、設定を編集中の場合は強制終了しません。

Windowsの「インストールされているアプリ」から削除できます。利用者データ領域の設定、外部モデル、利用者が追加したファイルは保持します。KotorinToysに所有記録のある本ツールの自動起動予約は、照合できる場合だけ整理します。旧版のStartupショートカットなど外部の自動起動登録は自動変更しません。必要なら旧環境の解除手順で整理してください。
