# MIC／MIC-RVC／SPK-RVCの常駐

VoiceMixer本体の画面を開かずに、マイクや指定スピーカーの再生音を、配信用・音声入力用・モニタ用の3出力へ送ります。ログイン時に起動し、前回正常に動作したモードと保存済みの出力状態を復元します。

更新日：2026-10-19。アプリ名は **VoiceMixerMicRouter**、常駐ツールの版は **1.0.17** です。本体とは独立して管理し、常駐ウィンドウと設定画面のタイトルにも表示します。以後、特別な指定がなければ末尾の数字を1ずつ増やします。

変更時に守る動作と既定値は[現行仕様書](mic-resident-spec.md)にまとめています。

| 表示 | 音声経路 |
|---|---|
| 緑の M：MIC | マイク → ONにした各出力 |
| 紫の R：MIC-RVC | マイク → RVC → ONにした各出力 |
| 青の S：SPK-RVC | 指定スピーカーの再生音 → RVC → ONにした各出力 |
| 灰色の X：送信停止 | すべての入力を送信しない。3出力とも無音 |
| 黄色 | 準備中・切替中。RVC読込中はMICへ戻せる |
| 赤 | 起動・実行エラー。10秒後に同じモードを再試行 |

## 操作

- **Shift+F5でMIC、Shift+F6でMIC-RVC、Shift+F7でSPK-RVC、Shift+F8で送信停止**へ切替。送信停止は再度押しても停止のままです。トレイのダブルクリックは設定画面を開きます。すでに開いている場合はその画面を手前へ戻します。
- トレイの右クリックで「MIC」「MIC-RVC」「SPK-RVC」「送信停止」を直接選択。
- 右クリックの「設定…」で、キー・表示・音声デバイス・RVCを設定。
- 設定画面を開いている間は、「設定…」以外のトレイメニューをグレーアウトします。「設定…」やダブルクリックで既存の画面が手前に戻ります。設定編集中も保存済みのキー操作を使えます。オーバーレイのクリック操作は停止します。
- **Shift+F9で出力1（配信用）、Shift+F10で出力2（音声入力用）、Shift+F11で出力3（モニタ用）**を個別にON／OFFします。トレイの同名項目でも変更でき、各出力の状態を保存します。初期状態は配信ON、音声入力OFF、モニタOFFです。
- **Shift+F12で「オフ → 数秒表示 → 常時表示 → オフ」**の順に切り替えます。トレイの表示項目も同じ順です。数秒表示は切替後4秒で消え、オフは即座に消えます。オフでは準備中・エラー時も表示しません。
- 画面右上のオーバーレイには、選択中の入力、表示設定・ノイズ・3出力のON／OFFを表示します。表示をオフにした場合はトレイと設定画面で状態を確認できます。
- オーバーレイの入力4モード、配信・音声入力・モニタ、表示、ノイズの各欄をクリックして操作できます。クリックしても、入力フォーカスは作業中のアプリに残ります。ON／OFFやキー名が変わっても、クリックできる範囲は変わりません。
- 「入力」の4ボタンは現在のモード1つだけが点灯します。「出力」の3ボタンは個別にON／OFFでき、ONは明るい背景、OFFは暗いグレー系です。OFFのボタンも押せます。ノイズ欄は「RVCノイズ抑制 ON」「RVCノイズ抑制 OFF」「RVC未設定」の3パターンです。
- ボタン上は指カーソル、背景やドラッグ中は移動カーソルになります。「数秒表示」のボタンには残り秒数が4→3→2→1と表示され、期限になると消えます。秒数の更新やマウスを重ねる操作では表示時間は延びません。
- オーバーレイは左ドラッグで移動できます。横または縦に4px以上動かすとドラッグになり、同時に欄のクリック操作は行いません。起動中は切替や再表示でも位置を保ち、再起動すると作業領域の右端から80px、上端から80pxへ戻ります。ドラッグ中は数秒表示が消えませんが、表示をオフにすると即座に消えます。
- オーバーレイ内は修飾キーを省いた `F5` などの表示で、キーで操作する際には設定した修飾キーも押してください。未割当キーは表示しません。
- 入力ボタンの直下に選択中の入力の、出力ボタンの直下に各出力固有の直近約1秒のレベルを表示します。非選択の入力や停止した出力は「無効」、入力の準備中は「ロード中」、障害時は「エラー」です。左が過去、右が現在。入力は緑、出力は青、大きすぎるレベルは赤になります。
- 送信停止中は入力取得・入力メーターを止め、3出力とも無音になります。各出力のON／OFF設定は保持され、MICやRVCへ戻すとその設定で送信を再開します。全出力をOFFにした場合も入力と常駐は継続し、OUTは無音になります。
- RVC時の右下の遅延表示は、最初は「遅延 測定待ち」です。3秒以上静かにした後の明瞭な声の立ち上がりを入力と出力で捉え、「遅延 約○ms」に更新します。測定後は値を保持し、最短3分後に同じ条件がそろったときだけ更新します。短いクリックだけでは測定しません。
- 遅延は稼働中の出力から3（モニタ）→1（配信）→2（音声入力）の順で測定先を選びます。全出力OFFでは「測定待ち」になります。アプリ内・RVC内の待ち時間とOSの再生待ちを含む概算で、物理スピーカー・通話アプリ・ネットワークの遅延は含みません。測定のために音声を遅らせることはありません。
- モード・音声設定の変更やデバイス再接続では測定待ちに戻ります。準備中・障害時や状態更新が途絶えたときは古い測定値を消して測定待ちに戻します。メーターや測定値の更新で数秒表示が延長されることはありません。測定先・待機状態・測定後の経過秒は `status.json` の `diagnostics.latency_measurement` でも確認できます。
- トレイまたは基本設定の**「短いノイズを抑制（RVC）」**で、孤立した短いクリック・衝撃音の抑制をON/OFFできます。MIC-RVCとSPK-RVCに共通適用し、既存の処理待ち中の音声を使うため、新しい待ち時間は設けません。声と重なる音や判別できない区間は通します。
- オーバーレイにもノイズON/OFFを表示します。MIC・送信停止でも「RVCノイズ抑制 ON／OFF」を表示し、「RVCを使用する」がOFFの場合は「RVC未設定」です。ON/OFFでモデルは再読込しませんが、遅延表示は測定待ちへ戻り、次の声から測り直します。
- 起動時は前回モードを復元。右クリックでMIC／MIC-RVC／SPK-RVC／送信停止の固定にも変更可能。
- 「現在のモードを再起動」でRVCを再準備。「RVCを終了してMICにする」でRVCを解放。「終了」で音声送信と常駐を終了。

音声を受けるアプリでは、入力マイクを **CABLE Output (VB-Audio Virtual Cable)** に設定してください。本ツールが送る再生側は「CABLE」または「CABLE Input」です。

音声入力用アプリでは、出力2に選んだ仮想ケーブルの録音側を入力に指定します。初期候補のVB-CABLE-Dを使う場合は、アプリ側でCABLE-Dの録音デバイスを選び、出力2をONにしてください。

RVCの初回起動にはモデルの読込時間がかかります。モデルの準備はバックグラウンドで進み、読込中でもShift+F5でMIC、Shift+F8で送信停止へ戻せます。読込完了後も最後に選んだモードを維持します。RVCを選択している間だけ「読込中」を表示し、準備完了までRVCの送信は無音になります。

RVCを一度選んですぐMICへ戻し、裏でモデルを準備しておく使い方ができます。初回変換に必要な追加モデルの読込も準備に含めます。準備用の音は送信しません。待機中のRVCで障害が起きた場合は、MICを継続しながらRVCだけを背景で復旧します。

一度起動するとMIC・送信停止中もモデルを保持し、次回は経路の変更だけで切り替わります。MIC・送信停止中のRVC入力は無音にし、処理とバッファを維持するためGPUメモリと一部の処理負荷は残ります。RVCエラー時は無音になり、原音には切り替わりません。

## リモートデスクトップ使用中

Windows標準のリモートデスクトップ接続（MSTSC）が前景にあるときも、常駐に有効登録したショートカットだけをローカル側の操作として受け取ります。「共存」の割当キーは他アプリやリモートPCへそのまま渡し、「上書き」は一致した主キーを可能な範囲で抑止します。長押しによる連続切替や通常アプリでの二重発火を抑止します。設定画面を開いたままでもキー操作できます。

対象は通常のデスクトップで動く `mstsc.exe` です。管理者として起動した接続画面、セキュアデスクトップ、別のリモートデスクトップクライアントは保証対象に含めません。実際のMSTSC接続での確認状況は[実機検証結果](../dev/testing/mic-resident-results.md)で確認してください。

## 設定画面

「基本設定」はオーバーレイ表示、ログイン時のモード、デバイス設定、その他（ノイズ抑制）の順です。

- オーバーレイ表示の3択（オフ／数秒表示／常時表示）と、ログイン時のモード。
- 入力マイク、入力スピーカー、出力1（配信用）、出力2（音声入力用）、出力3（モニタ用）の5欄。入力マイクだけが録音デバイス一覧を使い、それ以外は再生デバイス一覧から選びます。入力スピーカーには、そのデバイスで再生される音を取り込みます。
- 3出力にはそれぞれ「有効」チェックがあり、現在選択しているMIC音／RVC音をONの出力へ送ります。出力2は追加時にCABLE-Dを初期選択し、初期状態はOFFです。CABLE-Dが見つからない場合は未接続の候補として残り、ONにする際に接続できなければエラーになります。OFFの出力が未接続でも他の出力には影響しません。
- 各デバイス一覧の先頭に「既定のデバイス」「既定の通信デバイス」があります。選択するとWindowsの設定に従い、稼働中にOSの既定先を変更した場合も約2秒間隔の確認で再接続します。個別のデバイス名を選んだ場合はそのデバイスに固定します。
- ONにした複数出力へ同じ選択先を保存することはできません。通常／通信の既定先など別の選択が同じ再生デバイスにつながる場合は、出力1→2→3の優先順で一つだけ送信します。各出力のON／OFF設定は保持し、異なる先に戻れば追加送信も再開します。


「キー設定」にショートカットをまとめています。無効な行は修飾キーとキー選択がグレーアウトします。「有効」をチェックしてから割り当てます。OFFにしても選択値は保持します。

- **MIC／MIC-RVC／SPK-RVC／送信停止／入力モードを交互に切替／設定画面／出力1／出力2／出力3／オーバーレイ表示切替／ノイズ抑制切替**と各出力の押している間ONの14行。それぞれ「有効」、Ctrl・Shift・Alt・Windowsのチェックと、「なし」／A〜Z／F1〜F24の選択で設定します。各行の右端で「共存／上書き」を選べます。「なし」を選ぶと割当を解除します。修飾キーなしも選べますが、そのキーを他のアプリで使う際にも切り替わります。
- 既定キーはMIC Shift+F5、MIC-RVC Shift+F6、SPK-RVC Shift+F7、送信停止Shift+F8、出力1 Shift+F9、出力2 Shift+F10、出力3 Shift+F11、表示切替Shift+F12。交互切替・設定画面・ノイズ切替は「なし」です。同じ組合せを複数操作へ割り当てると適用時にエラーを表示します。

「RVC設定」先頭の「RVCを使用する」をOFFにして適用すると、RVCを停止し、オーバーレイはMIC・停止の2ボタンになります。RVC選択中はMICへ戻り、読込中でもMICを使いながら背景で解放します。RVC関連の設定・キーはグレーアウトしますが値を保持します。ONに戻すだけではロードせず、次のRVC選択で準備します。

「RVC設定」ではモデル、Index、ピッチ、フォルマント、F0方式、Index適用率、処理時間、音量、ゲート、CPU数、JIT、ノイズ抑制の全15項目を設定します。「＊」付きのモデル・処理時間等の変更時だけRVCを再起動します。数値の範囲外や適用エラーは画面内に表示されます。

「適用」で全タブの設定を保存・反映し、画面を開いたまま編集を続けられます。「閉じる」は最後の適用後の未保存分だけを破棄します。キーや表示だけを変更しても音声デバイスやモデルは再起動しません。音声設定の適用に失敗した場合は旧設定への復旧を試み、失敗理由を表示します。

## スピーカーの音を変換して配信する

1. 基本設定の「入力スピーカー」で、変換したい音の再生先を選びます。
2. 「出力1（配信用）」にVB-CABLEなど別のデバイスを指定し、「有効」をチェックして保存します。
3. Shift+F7でSPK-RVCへ切り替えます。配信アプリでは配信用デバイスの録音側を入力にします。

SPK-RVCで入力スピーカーとONの出力が同じ場合は、送信を止めてエラーを表示します。該当出力をOFFにするか別のデバイスを選ぶと解消できます。OFFの出力先との一致は問題ありません。設定適用時は不正な組合せを拒否して旧設定を維持します。スピーカーで再生される全音声が取り込み対象です。

## 起動スクリプト

PowerShell 7で実行します。常駐済みの場合は既存のプロセスを切り替えます。

```powershell
cd C:\develop\VoiceMixerMicRouter
pwsh -File .\dev\scripts\Start-MicDirect.ps1
pwsh -File .\dev\scripts\Start-MicRvc.ps1
```

前回モードで起動／切替／終了：

```powershell
pwsh -File .\dev\scripts\Start-MicRouter.ps1
pwsh -File .\dev\scripts\Start-MicRouter.ps1 -Mode SpeakerRvc
pwsh -File .\dev\scripts\Start-MicRouter.ps1 -Mode Toggle
pwsh -File .\dev\scripts\Start-MicRouter.ps1 -Mode Muted
pwsh -File .\dev\scripts\Start-MicRouter.ps1 -Mode Stop
pwsh -File .\dev\scripts\Start-MicRouter.ps1 -Mode Settings
pwsh -File .\dev\scripts\Start-MicRouter.ps1 -Mode ReleaseRvc
```

`Muted` は常駐を維持して送信だけ停止し、`Stop` は常駐を終了します。

各出力切替の直下に「押している間ON」のキー設定があります。初期状態は「なし」です。押下中の出力だけONになり、他の出力は一時OFFになります。すべて離すと普段のON/OFFへ戻ります。普段からONなら離してもONのままです。3出力を同時に押せます。設定画面を開いたままでもP2Tを使え、画面を開くだけでは押下中の状態を解除しません。

設定画面の上部は「基本設定」「キー設定」「RVC設定」のタブです。選択中のページをタブの見た目で確認でき、Ctrl+Tabでも切り替えられます。ページを切り替えても未保存の入力は保持します。

用途名は基本設定の各出力行で直接編集できます。適用すると、ショートカットの操作名・トレイ・オーバーレイにも反映されます。用途名は表示だけの設定で、音声処理は3出力とも共通です。全角5文字まではキー・ON/OFFとともに省略せず表示し、それより長い名前はオーバーレイ内だけ省略します。未割当の`[なし]`は表示しません。

## 配備と自動起動

```powershell
cd C:\develop\VoiceMixerMicRouter
pwsh -File .\dev\scripts\Install-MicRouter.ps1
```

`release/MicRouter/` に最適化済みEXEを置き、現在のユーザーのスタートアップにショートカットを登録して起動します。既存の設定は保持します。更新時は先に常駐を終了してください。

RVCはmic-settings.jsonのplugin_directoryに指定したpluginsフォルダー内のモデル・CUDA実行環境を使用します。EXEだけを別PCへコピーしてもRVCは動作しません。初期設定は接続中の既定の実マイク、出力1に通常のVB-CABLE、出力2にCABLE-D（初期OFF）、KahoA（ピッチ+10、rmvpe）です。Windows既定デバイスは変更しません。

自動起動解除：

```powershell
pwsh -File .\dev\scripts\Unregister-MicRouterStartup.ps1
```

解除しても設定やEXEは削除されません。

## 設定・診断

`release/MicRouter/mic-settings.json` に5デバイス欄、14のキー設定、3出力のON／OFF、RVCパラメーター、前回モードなどを独立して保存します。VoiceMixer本体のプロジェクト設定は変更しません。

旧3行・6行・7行・8行・9行・11行のキー設定は14行へ移行し、旧既定の表示・モニタ・送信停止の割当だけを新しい既定へ移します。独自の割当や無効設定、「なし」は保持します。追加・移動したキーが既存の独自キーと競合する場合は、追加・移動側を無効にします。保存済みのデバイス、モニタのON／OFF、RVC設定も引き継ぎます。

通常は画面で設定し、JSONを直接編集する場合は先に常駐を終了してください。`rvc_parameters` は[CUDAプラグイン](../plugins/rvc-cuda/README.md)と同じ定義を利用します。

表示設定は `overlay_mode` に `off`／`brief`／`always` として保存します。旧版の常時表示ONは常時表示、OFFは数秒表示へ引き継ぎます。

`status.json` に現在のモード、段階、最終更新時刻、プロセスID、実測の音声診断を保存します。古いファイルだけでは稼働中とは判断せず、時刻とプロセスも確認してください。

デバッグ起動：

```powershell
cd C:\develop\VoiceMixerMicRouter
cargo run --manifest-path .\src\src-tauri\Cargo.toml --bin voicemixer-mic -- --config .\release\MicRouter\mic-settings.json
```

常駐を停止してから `--check direct`、`--check rvc`、`--check speaker_rvc`、`--check muted` のいずれかを加えると、10秒間の実デバイス試験を行い、設定と同じフォルダーへ診断JSONを保存します。録音は行いません。信号取得・ノード起動と、音質を聴いての確認は別です。

オーバーレイは「設定」「入力」「出力」の3行で左ラベルとボタンの左右端を揃え、設定は2等分、入力は4等分、出力は3等分の幅にしています。

P2T押下中の出力ボタンは青い背景と`P2T`の文字で通常ONと区別する。非対象出力はOFF表示となる。3出力のP2Tを同時押しした場合は押している出力をすべてONとし、一部を離した場合も残る押下だけをONにする。すべて解放すると通常表示・通常設定へ復帰する。切替は非対象の停止を先に行い、対象をその後に開始する。P2Tで通常設定を保存・上書きしない。

設定画面を開いたままでも、モード・各出力・オーバーレイ表示・ノイズ・P2Tのショートカットを使えます。キーで変えた項目は保存され、画面の該当項目にも反映します。他の未適用の編集は残ります。同じ項目を編集中にキーで変更した場合は、そのキー操作を優先します。新しく編集中のキー割当は「適用」まで有効になりません。トレイメニューとオーバーレイのクリックは設定中も無効です。

## キー設定の共存と上書き

共存は他アプリにもキー入力を渡す現在の動作です。上書きは一致した主キーの押下・長押し・解放を抑止します。修飾キー単独やOSの保護された操作まで完全に無効化するものではありません。両方ともMSTSC使用中の検知を維持します。旧設定には共存を補います。

キー設定はオーバーレイに合わせ、表示・ノイズ・設定画面、入力、出力の3群に並び、群の間に区切り線があります。出力ごとの押している間ONは各切替の直下です。現在の旧既定Alt+F5〜F12はShiftへ移行し、独自割当・無効行・なしを保持します。独自のShift割当と競合する旧既定はAltのまま残します。

基本設定の「公開GitHub」から[独立リポジトリ](https://github.com/KotorinChunChun/VoiceMixerMicRouter)を開けます。

モデルとIndexはコンボボックスへ任意のフルパスを直接入力・貼り付けできます。「フォルダーを開く」は入力中のファイルの親フォルダーを開きます。空欄なら既定の保存フォルダーを開き、存在しない場所は作成せずエラーを表示します。各RVCラベルと短いノイズ抑制にマウスを重ねると原理・影響・再起動要否を確認できます。
